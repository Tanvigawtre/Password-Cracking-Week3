# 🔐 PASSWORD CRACKING – WEEK 3

### Cybersecurity Internship | Networkwalks

## 📌 Project Overview

This repository documents my Week 3 tasks as part of the Cybersecurity Internship at Networkwalks. This week's focus was on Password Cracking, understanding password vulnerabilities, exploring hashing techniques, and learning how attackers identify weak passwords using various cybersecurity tools.

The practical exercises helped me understand password security mechanisms and the importance of protecting sensitive credentials.

## 🎯 Objectives

- Understand the fundamentals of password cracking.
- Learn about different password hashing algorithms.
- Explore various password-cracking techniques.
- Identify and analyze password hashes.
- Gain practical experience with password-cracking tools.
- Understand dictionary attacks and brute-force attacks.
- Learn effective methods for improving password security.

## 🛠️ Tools & Technologies Used

- **Kali Linux:** Linux distribution used for cybersecurity testing.
- **John the Ripper:** Password security auditing and password recovery tool.
- **Hashcat:** Advanced password recovery and hash-cracking tool.

## 🔍 Practical Activities

- Studied password-cracking fundamentals and methodologies.
- Explored different types of password hashes.
- Practiced hash identification and analysis.
- Worked with password-cracking tools.
- Explored dictionary-based and brute-force techniques.
- Analyzed password strength and common security weaknesses.

## 📚 Key Learnings

Through this week's activities, I gained practical knowledge of password security, hashing mechanisms, and commonly used password-cracking techniques.

I also learned how weak passwords can create security risks and why strong passwords, secure hashing algorithms, and proper authentication practices are essential for protecting user accounts.
